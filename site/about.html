The boringly responsible bit

Time travel, minus the login.

MuseAi reads the JSON you export from Google Takeout and turns it into Markdown and JSON. The front end you are looking at is a static, animated wrapper around that local-first idea.

Three small moves

It remembers the details.

  • Count the repeats: music records are grouped by video ID when available, so different versions stay different.
  • Keep the oddballs: songs heard once go into an appendix rather than pretending they are lifelong favorites.
  • Group the vibe: genre and instrumental hints are inferred with transparent offline heuristics.

Deploy it anywhere static files go

GitHub Pages. Cloudflare Pages. Same little rewind.

Every link is relative, every page is a real `.html` file, and there is no server-only assumption in the marketing site. Drop `site/` into a Pages build, or serve it as a static Worker asset bundle.
